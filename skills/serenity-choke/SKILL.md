# Serenity A股卡脖子框架(Agent 决策版)

## 核心使命
沿产业链向上游追溯,找到"一旦断供整条万亿产业就地震"的关键瓶颈环节;那个环节里
有技术壁垒的小盘股,弹性最大。这不是基本面也不是纯技术,而是**供应链瓶颈分析**。

## 用在本模拟盘里怎么做
你拿到的是确定性引擎打过分的候选股(get_candidates),其中 `serenity` 字段已标出命中的
卡脖子赛道标签(由 config 的定性清单判定)。用本框架在候选里做**优先级排序与取舍**:

1. **优先级**:命中 serenity 标签 + 多因子 score 居前 + 资金面健康(get_stock_detail 看
   `fund_flow_recent` 与 `mainflow_ratio_nd_avg_pct`,**占比单位是 %**;金额看 main_net_yi)的标的,优先考虑。
2. **瓶颈成色自检**(满足越多越好):
   - 技术壁垒高(专利/know-how 深)、产能扩张周期长(2~5 年);
   - 国产自给率低、单一/寡头供应、不可替代、有出口管制/地缘风险。
3. **排除伪概念**(命中任一就放弃):
   - 蹭热点非主营;格局分散无护城河;壁垒低易扩产;
   - 估值已充分反映(过于知名、涨幅过大);流动性差(成交额过低)。
4. **多空确认**:主力净流入占比持续为正(main_ratio_pct / mainflow_ratio_nd_avg_pct) + 估值分位不高 + 政策支持,才值得挂单;
   主力净流出、无人问津、政策压制则观望。

## 与本系统硬规则的关系
- 你只负责"选哪只、挂多少限价";买不起/限价不合理/超持仓上限会被系统拒绝。
- 卡脖子逻辑是**加分项与排序依据**,不是无视风控的理由;盘面差时宁可不买。

## 一句话定位法
对每个候选,先用一句话说清它"卡在哪条产业链的哪个环节、为什么难被替代"。
说不清的,就当作伪概念排除。

> 本框架仅用于模拟盘研究,不构成投资建议。
