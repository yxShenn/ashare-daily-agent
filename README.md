# A股每日选股 Agent

一个面向中国 A 股的**自我进化选股 + 模拟实盘工作流**:每天推荐一只偏高胜率的短线标的,用 **10 万初始资金的虚拟账户模拟实盘买卖**确认真实胜率,自动复盘并以**严格 walk-forward** 持续优化交易策略。

> ⚠️ 仅用于研究与模拟,**不构成任何投资建议**,不接入券商实盘资金。

## 核心闭环

```
模拟交易结算(建仓/止盈止损/到期) → 复盘命中率 → 严格walk-forward优化权重
   → 用新策略选股(Top1) → 挂次日建仓单 → 写日报 → 次日循环
```

## 策略说明

- **选股范围**:全 A 股,经风控过滤(剔除 ST/退市、北交所、次新首日、停牌、流动性不足、接近涨跌停难买入)。
- **打分模型**:多因子横截面 z-score 加权 —— 技术面(均线/MACD/RSI/KDJ/布林/动量/量能/回踩)+ **资金面(主力净流入近5日占比均值,大资金流向)**。资金流向走 efinance 源(绕过被封锁的东财 akshare 接口),含历史可参与 walk-forward 优化。
- **智能动态出场**(`config.yaml` 的 `exit`,实盘/回测共用 `exits.py`,不再机械到期):按优先级——① 硬止损 `-5%`(本金保护);② **移动止盈**(浮盈 ≥5% 后启动,自最高点回撤 5% 离场,让盈利奔跑);③ 收盘**跌破 MA10** 趋势离场;④ **级联止损**(持有 ≥2 日且浮亏 ≥3%,或 ≥6 日仍≈持平的"死钱"换仓);⑤ 最长持有 30 日防僵尸仓。`holding_days`/10% 仅保留用于"信号命中率"统计与 `winrate` 优化目标。
- **严格 walk-forward 自优化**:回测窗口按时间切成"训练集(较早)+ 验证集(最近、样本外)";只在训练集随机搜索挑参,用从未参与挑选的验证集估计样本外表现;仅当样本外不劣于基线时才更新 `data/active_config.json`,避免过拟合上线。
- **两种优化目标**(`config.yaml` 的 `optimize.objective`):
  - `winrate`:最大化每日 Top1 的命中率。
  - `profit`(默认):**在最大回撤 ≤ 15% 约束下最大化累计收益**——按真实出场规则模拟每笔收益、串成权益曲线,以"赚最多 + 本金不大亏"为目标。
- **本金保护(回撤熔断)**:账户从历史峰值回撤达 `risk.max_drawdown`(默认 15%)时,**暂停建仓**并撤销待建仓单,直至权益修复。

## 虚拟账户(模拟实盘,确认真实胜率)

- 初始资金 10 万,按权益比例分配仓位(默认每笔 20%,最多 5 笔并发)。
- 真实 A 股规则:100 股整数倍、**T+1**、佣金(双边,最低 5 元)、印花税(卖出)。
- **建仓时机**(实时模式 `run_live.py`):启动只做复盘+优化;到 `live.select_time`(默认 **14:00**)用**实时数据择时选股**,按 `entry_discount` 定好**目标买入价**并挂**限价买单**;盘中现价**回调到目标价才成交**(未到价继续等,`pending_ttl_days` 超期撤单)。T+1 仅约束卖出。
- **资金可买性**:选股阶段即按账户资金过滤——可买单价上限 = `权益 × max_position_fraction ÷ 100`(10万本金、35% → 约 350 元/股),买不起的高价股不进入推荐。**高价股**预算不足 1 手时在单仓上限内**至少买 1 手**(可关 `allow_one_lot`)。
- **出场**:采用上文「智能动态出场」规则(移动止盈 / 趋势离场 / 级联止损 / 硬止损 / 最长持有)。
- **诊断日志**:每个 tick 打印是否取到实时行情、可建仓数;每只**未建仓的标的会给出原因**(T+1 次日生效 / 回撤熔断 / 1 手超预算 / 现金不足 / 持仓已满),日报亦同步记录。
- 记录每笔成交盈亏、权益曲线与**真实胜率**(以平仓收益 > 0 计胜)——这是比"信号命中率"更诚实的成绩单。

## 安装

```bash
pip install -r requirements.txt
```

## 使用

**每个交易日运行 `run_live.py` 即可**——它在一个进程里完成全部工作:启动复盘+优化 → 下午实时择时选股挂限价单 → 盘中等回调成交 + 智能出场 → 收盘结算 + 日报。

```bash
python run_live.py                  # 交易日开盘前后启动,跑完当日自动结算退出
python run_live.py --once           # 复盘+优化 + 选股 + 一次盘中 tick(调试)
python run_live.py --eod-now        # 复盘+优化 + 选股 + 立即收盘结算(补跑)
```
> 关键节奏在 `config.yaml` 的 `live` 配置:`interval_seconds`(轮询间隔)、`select_time`(选股时间)、`entry_discount`(目标买入价折扣)、`pending_ttl_days`(限价单有效期)。

运行产物:
- `data/journal.db`:推荐/评估台账 + 虚拟账户(持仓/成交/权益曲线,SQLite)
- `data/active_config.json`:当前最优因子权重
- `data/strategy_history.jsonl`:每次优化的历史记录
- `data/reports/report_*.md`:每日日报(含虚拟账户战绩)

## 目录结构

```
ashare_agent/
  config.py     配置加载(默认 config.yaml + 优化覆盖)
  data.py       akshare 数据适配 + 实时报价 + 本地缓存(懒加载)
  store.py      SQLite 连接 + 推荐/评估台账
  universe.py   选股池 + A股风控过滤
  factors.py    多因子向量化计算(point-in-time)
  strategy.py   横截面标准化 + 加权打分(实盘/回测共用)
  recommend.py  每日 Top1 选股
  evaluate.py   历史推荐信号命中率复盘
  optimize.py   严格 walk-forward 策略自优化
  exits.py      智能动态出场规则(实盘/回测共用)
  portfolio.py  虚拟账户(资金/持仓/成交/权益曲线 + 交易费用)
  paper_trade.py 模拟交易逻辑(限价建仓/智能出场)
  report.py     日报生成
run_live.py     唯一入口:盘中实时循环(选股/交易/优化/结算/日报)
config.yaml     可调参数
```
